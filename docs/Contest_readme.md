## 2026 관광데이터랩 프롬프톤 — AI-DO (기차역 가챠 + AI 체크리스트)

**결과**: 예선 통과 (200팀 중 15팀) → 본선 탈락

**원인**
1. 재미 중심 컨셉 — 심사는 "문제 해결 + 데이터 근거"를 봄. 공익성(인구감소지역 가중치)은 후처리 티가 남
2. 측정 가능한 지표 부재 — 기대효과가 전부 검증 안 된 구조적 논리
3. 챗봇 + 웹서비스 이원화 — 10분 발표에서 둘 다 얕아짐. 프롬프톤인데 프롬프트가 본체가 아니었음
4. "AI 관광 추천" 골격 자체가 레드오션 — 가챠 포장을 벗기면 차별화 없음

**교훈 (다음 공모전 체크리스트)**
- [ ] "누가 뭘 못 해서 곤란한가" 문제 정의부터 시작 (재미/아이디어에서 출발 금지)
- [ ] 문제의 크기를 공공데이터/통계 숫자로 제시
- [ ] 심사기준 항목별로 기획서 섹션 역산 매핑
- [ ] 핵심 하나에 올인, 산출물 이원화 금지
- [ ] 기존 수상작 패턴 분석 후 기획 (수상작 = 명확한 현안 + 데이터 교차 + 실현 가능 해결책)
